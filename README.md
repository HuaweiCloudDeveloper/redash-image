## Project Introduction
[Redash](https://github.com/getredash/redash) is an open-source data query, analysis, and visualization tool focused on simplifying the data exploration and collaboration process, suitable for enterprise-level data analysis scenarios.

**Redash Features:**
- **Browser-based:** All operations are completed in the browser, supporting the generation of shareable URLs.
- **Ease of use:** You can efficiently process data immediately without mastering complex software.
- **Query Editor:** Quickly write SQL and NoSQL queries through the schema browser and auto-completion features.
- **Visualization and Dashboards:** Create beautiful visualizations through drag-and-drop operations and combine them into a single dashboard.
- **Sharing Function:** Easily share visualizations and their associated queries, supporting peer review of reports and queries.
- **Scheduled Refresh:** Automatically update charts and dashboards at custom time intervals.
- **Alert Function:** Define conditions and receive immediate alerts when data changes.
- **REST API:** All operations that can be completed in the user interface can also be achieved through the REST API.
- **Wide Range of Data Source Support:** An extensible data source API natively supports many common databases and platforms.

This project provides an open-source image product [**Redash Data Query and Visualization Tool**](https://marketplace.huaweicloud.com/contents/1c70adbb-d0fc-4572-891e-7112bfc165c0#productid=OFFI1129684441106587648), which has pre-installed the Redash software and its related operating environment and provides a deployment template. Come and refer to the usage guide to easily start an "out-of-the-box" and efficient experience!

> **System requirements are as follows:**
> - CPU: 2GHz or higher
> - RAM: 4GB or larger
> - Disk: At least 40GB
